# Languages

The app has two interface languages: English and **Indonesian (Gen Z)**. The style guide for the Indonesian
voice is `i18n-id-style.md`. The language is stored per device (`yulu.lang.v1`). With nothing stored, a browser
set to Indonesian starts in Indonesian, everything else in English. Switching reloads the page, so course data,
generated questions and anything memoised are all built in one language. Switch in Profile, or with the EN / ID
chip on the home screen.

## Interface text

`t('English source', { name: value })` (`src/lib/i18n.ts`) returns the English, or the Indonesian from
`src/i18n/id/*.ts` keyed by that exact English string. A missing entry shows English, never a blank.

- The first argument must be a string literal. Build whole sentences with `{placeholders}` so Indonesian can
  reorder; never join fragments. Plurals are two strings.
- Pass Hanzi, pinyin, numbers and course data as placeholders, never inside the translatable string.
- `tests/i18n-coverage.test.mjs` fails if a `t()` call has no Indonesian entry, a placeholder is missing, or an
  entry is a copy of the English. `node scripts/i18n/check-conflicts.mjs` finds one English string translated two ways.
- `node scripts/i18n/scan-ui.mjs src/screens src/components` lists user-visible English still outside `t()`.

## Course content

Meanings, translations, grammar explanations and memory hooks live in the source JSON in English. Indonesian is an
**overlay** in `src/data/i18n/id/`: a map from the path of an English string to `[hash of that English, translation]`.
`applyOverlay` (`src/lib/localize.ts`) writes the translations into the loaded data once, so screens read them without
knowing. If the English later changes, the hash no longer matches and that entry is skipped (English shows) instead
of a translation of a sentence that no longer exists. `tests/i18n-content.test.mjs` fails on a stale entry and
requires at least 99.5% of each course's strings to be translated.

Covered: HSK 4A (vocabulary, text translations, grammar, extras, exercises), the per-word teaching hooks,
Kerja and Jiaocheng (meanings, dialogues, notes, hooks, grammar), and Magang and Interview (chapter titles, lesson
text, quizzes, and the meaning and memory hook of every Chinese term). Not covered: the English-language reading
content of Books (about 100,000 words of study-guide prose for five business books, plus the per-chapter teaching
tables in `src/lib/bookLearning.ts`; only the Books interface is translated), and the CC-CEDICT dictionary fallback
for words outside the courses.

### Regenerating a translation

```
node --experimental-strip-types scripts/i18n/extract-content.mjs <course> <workdir>   # writes numbered chunks
# translate each chunks/NN.json into out/NN.json: {"<id>": "<translation>"}
node scripts/i18n/check-chunk.mjs <workdir>/<course>/chunks/NN.json <workdir>/<course>/out/NN.json
node --experimental-strip-types scripts/i18n/merge-content.mjs <course> <workdir>     # writes src/data/i18n/id/*.json
```

Courses are defined in `scripts/i18n/sources.mjs`. The checker confirms every id is present, Chinese characters and
numbering are untouched, and no sentence is left in English.
