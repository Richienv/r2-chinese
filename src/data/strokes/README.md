# Introductory Hanzi stroke data

`intro.json` bundles the unchanged Hanzi Writer Data 2.0.1 stroke paths, medians, and radical indexes for the first lesson's introductory words: 法律、俩、印象、深、熟悉、不仅、性格. The introduction can draw these characters without contacting an external CDN. Other characters use Hanzi Writer's pinned 2.0.1 data endpoint and retain a static text fallback when unavailable.

Source: <https://github.com/chanind/hanzi-writer-data>, distributed at <https://cdn.jsdelivr.net/npm/hanzi-writer-data@2.0.1/>. The data is from Make Me a Hanzi and Arphic PL KaitiM GB / UKai fonts.
